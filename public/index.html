Set up rockdesign

Run this app locally. Five steps.

  1. 1
    Install Claude Code

    rockdesign drives your local claude CLI — no extra API key needed. The npm install works on macOS, Windows, and Linux.

    npm install -g @anthropic-ai/claude-code
claude
  2. 2
    Clone the repo

    Or fork it first and replace the URL.

    git clone https://github.com/your-user/rockdesign.git
cd rockdesign
  3. 3
    Install dependencies

    Only express. Requires Node 18+.

    npm install
  4. 4
    Start the server

    Default port is 4173. Override with PORT env var (PORT=5050 npm start on macOS/Linux, $env:PORT=5050; npm start in PowerShell).

    npm start
  5. 5
    Open in browser

    Visit the URL in any modern browser. PNG export uses Chrome / Chromium / Edge / Brave from the standard install location — set CHROME_PATH env to override.

    http://localhost:4173
Compatibility · Tested on macOS, Windows 10/11, and Ubuntu. Needs Node ≥ 18 and Git. PNG export needs a Chromium-based browser; everything else is built-in. Drop images or .fig files into the chat and Claude will Read them during generation.
